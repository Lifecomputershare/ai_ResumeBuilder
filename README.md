# AI Resume Builder Core Engine

This repository contains a lightweight, ethical resume intelligence engine focused on ATS-aware content workflows.

## Included capabilities

- Resume summary generation
- Experience bullet generation
- Resume rewrite and improvement
- ATS keyword optimization
- Job description alignment
- Resume quality scoring (JSON)
- Skill gap identification
- Cover letter generation
- Resume section suggestions by level
- Safety gate for unethical requests

## Run tests

```bash
pytest -q
```
